# 获取帮助

## man

man命令用于获取非内建命令的指令帮助

语法：**man  命令名**

## help

help命令用于获取shell内建命令的帮助

语法：**help 命令名**

## tab

补全键：用于展示当前输入字符可能产生的命令
**例如：输入user之后按下tab键，会弹出所有命令中含user的命令**

==**所以学习Linux不用死记全部命令，核心法则是：
1. 牢记常用命令
2. 对不常用命令有印象，知道要什么命令来操作
3. 输入部分命令->tab补全
4. help/man寻找帮助
5. 问ai
