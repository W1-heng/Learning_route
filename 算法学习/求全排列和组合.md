# 全排列
方法一：dfs搜索+回溯(暴力)
```cpp
int res[10];//每一次的结果记录
bool done[10]={0};//当前数字(下标）是否被用过
void dfs(int dep)//这里的深度表示的其实就是在选第几个数
{
    if(dep>n)
    {
        for(int i=1;i<=n;i++)
        {
            cout<<res[i];
        }
        cout<<endl;
        return ;
    }//一轮深搜完毕，输出结果
    for(int i=1;i<=n;i++)//搜索
    {
        if(!done[i])
        {
            done[i]=1;
            res[dep]=i;
            dfs(dep+1);
            done[i]=0;//回溯进行下一次搜索，记得把当前搜索用过的状态恢复
            
        }
    }
    
}
```

搜索树：

              空
          /    |    \
         1     2     3
       /  \   / \   / \
      2    3 1  3  1   2
      |    | |  |  |   |
     3    2  3  1  2   1
**复杂度：O（n！）


# 组合

方法一：dfs搜索+回溯+剪枝（优化搜索树）
==核心问题：组合不看顺序，用求全排列的方法求会导致同一组合重复求==

剪枝原理：**规定一个排列顺序，这样就可以不受顺序影响**
```cpp
#include <iostream>
#include <iomanip>
using namespace std;
int res[21];//每轮组合结果
bool sta[21]={0};//当前数字是否被用过，状态数组
int n,r;
int start=1;//用来剪枝，为了得到组合而不是排列，规定选取顺序，当前选取数字必须在前一个数字的后面
void dfs(int dep)//组合问题，要进行剪枝
{
    int m=0;
    if(dep>r)
    {
        for(int i=1;i<=r;i++)
        {
           cout << setw(3) << res[i];

        }
        cout<<endl;
       
        return;
        
    }
    for(int i=start;i<=n;i++)
    {
        if(!sta[i])
        {
            sta[i]=1;
            res[dep]=i;
            start=i;//更新开始点，确保后面选的数在当前数的后面，这样子顺序就唯一了，就可以当作是组合了
            dfs(dep+1);
            sta[i]=0;
            
        }
    }
}
int main()
{
    cin>>n>>r;
    dfs(1);
    return 0;
}
```
**start规定了搜索范围必须从当前已被选取的数字的前面开始（以原被搜索数组为基准）**

==**如果要进行多轮组合搜索，记得每次开始前重置start**==

# 康托展开（Cantor Expansion）总结

## 1. 康托展开作用

康托展开用于：

> 求一个排列在所有排列中的字典序排名。

例如：

n=3，数字：
```

1 2 3

```

所有排列：
```

1 2 3 第1个  
1 3 2 第2个  
2 1 3 第3个  
2 3 1 第4个  
3 1 2 第5个  
3 2 1 第6个

```

排列：
```

2 3 1

```

它的排名：
```

4

```

如果从 0 开始编号：
```

rank = 3

```

---

# 2. 核心思想

对于排列：
```

a[1] a[2] ... a[n]

```

依次计算：

当前数字前面有多少个更小的排列。

例如：
```

2 3 1

```

---

## 第一位

当前：
```

2

```

比它小的数字：
```

1

```

数量：
```

1

```

后面有：
```

2!

```

种排列。

贡献：
```

1 * 2! = 2

```

---

## 第二位

剩余数字：
```

1 3

```

当前：
```

3

```

比它小：
```

1

```

数量：
```

1

```

后面：
```

1!

```

贡献：
```

1 * 1! = 1

```

---

## 第三位

当前：
```

1

```

比它小：
```

0

```

贡献：
```

0 * 0! = 0

```

---

总排名：
```

2 + 1 + 0 = 3

```

如果从1开始：
```

rank = 4

```

---

# 3. 数学公式

第 i 位：

记：
```

c[i]

```

表示：

> 当前数字右侧未出现数字中，比它小的数量


贡献：
```

c[i] * (n-i)!

```


所以：
```

rank = Σ c[i] * (n-i)!

````

---

# 4. C++实现（普通版本）

```cpp
int cantor(int a[], int n)
{
    int ans = 0;

    for(int i=0;i<n;i++)
    {
        int cnt = 0;

        for(int j=i+1;j<n;j++)
        {
            if(a[j]<a[i])
                cnt++;
        }

        ans += cnt * fac[n-i-1];
    }

    return ans;
}
````

复杂度：

```
O(n^2)
```

# 5. 逆康托展开

作用：

> 已知排名，求对应排列。

例如：

已知：

```
rank = 3
```

恢复：

```
2 3 1
```

---

## 思路

假设：

n=4

数字：

```
1 2 3 4
```

rank：

```
14
```

第一位：

因为：

```
3! = 6
```

计算：

```
14 / 6 = 2
```

取剩余数字第2个：

```
3
```

剩余：

```
1 2 4
```

新的 rank：

```
14 % 6 = 2
```

第二位：

```
2 / 2! = 1
```

取：

```
2
```

继续即可。
