```cpp
BigNum qpow(BigNum base, long long exponent)
{
    // 初始值 = 1
    //BigNum ans(500, 0);
    ans[0] = 1;
    while (exponent > 0)
    {
        if (exponent & 1)//当指数是奇数时，可以先将一个底数乘给结果，其余底数当指数变为一时再统一传给结果
            ans = mul(ans, base);
        base = mul(base, base);
        exponent >>= 1;//让当前数乘自己，这样每次，幂都可以除以二。
        
    }
    return ans;
}
```
原理：把幂次拆成二进制，底数不断平方，遇到二进制位为 1 则乘入结果，时间复杂度 \(O(\log n)\)，解决普通幂 \(O(n)\) 超时问题。
