**前提，有序数组，范围左闭右开
# lower_bound(起始位置，终止位置，数字（val)）

返回第一个出现这个数的地址，使得在这个地址前面插入该数字，数组有序性不变

# upper_bound(起始位置，终止位置，数字（val))

返回第一个出现这个数(==后面==）的地址，使得在这个地址前面插入该数字，数组有序性不变


例如数组a： 1 1 2 2 3
lower_bound（a，a+5,2）返回2
upper_bound（a，a+5,2）返回4

**==所以，upper_bound(起始位置，终止位置，数字（val))-lower_bound(起始位置，终止位置，数字（val)）可以表示该有序数组中这个数字出现的次数==**

时间复杂度O(logn)
注意地址其实是返回的==指针==。


想要存为int类型一般这样用

```cpp
int pos=lower_bound(a.begin(),a.end(),num)-a.begin();
```
