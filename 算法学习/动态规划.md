
当看到两种操作，两种选择.....意味着两种状态，考虑用dp

# 0/1背包

## 问题模型

有 `n` 个物品，每个物品：

- 重量：`w[i]`
- 价值：`v[i]`

有一个容量为 `m` 的背包。

每个物品：

- 只能选 **0次或1次**
- 不能重复选择

目标：

> 在不超过背包容量的情况下，使选择物品的总价值最大。

## 一维dp模板
```cpp
dp[j]//表示在j的容量下能选择的最大物品价值
```
表示当前处理过的物品，容量为j时的最大价值

## 一维状态转移方程
```cpp
dp[j]=max(dp[j],dp[j−w[i]]+v[i])//dp[j]表示不选择第i个物品的状态，dp[j-w[i]]+v[i]表示不选择第i物品的状态，两个状态取最大值就是当前j容量当前能获得的最大价值。
```

## 二维dp模板

定义：

```
dp[i][j]
```

表示：

> 考虑前 i 个物品，容量为 j 时最大价值


## 二维状态转移方程
```cpp
dp[i][j]=max( dp[i-1][j], dp[i-1][j-w[i]]+v[i] );
```

## 核心代码
```cpp
for(int i=1;i<=n;i++) { //表示当前要选第i个物品
		
		for(int j=m;j>=w[i];j--) //每个容量对第i个物品进行评估，看是否要在该容量下选它，j>=w[i]限制了只处理装的下的容量。
		{ 
			dp[j]=max( dp[j], dp[j-w[i]]+v[i] ); 
		}//这里必须倒序遍历
 }
```

## 容量必须倒序遍历！！！

==**原因：要保证dp[j-w[i]]还是上一轮的状态（也就是还没有选物品i）的状态，否则，会导致当前容量重复选取物品！！！
